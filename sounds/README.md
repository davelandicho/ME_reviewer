# Sounds

Drop meme clips here as .mp3 files with these exact names:

| File          | Plays when |
|---------------|------------|
| correct.mp3, correct-1.mp3 … correct-5.mp3 | Right answer (one is picked at random) |
| wrong-1.mp3 … wrong-5.mp3 | Wrong answer (one is picked at random) |

You don't need all of them — missing files are skipped. If no clip is found, a beep plays.
To use other names or more clips, edit `SOUND_FILES` at the top of `app.js`.
Keep clips short (1–3 seconds) and small (under ~200 KB).
